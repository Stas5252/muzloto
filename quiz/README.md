# Вне очереди

Отдельный квиз для компании. [Открыть на GitHub Pages](https://stas5252.github.io/muzloto/quiz/).

## Подготовка

1. В главном меню нажмите «Создать комнату» для игры со стартовым набором или «Редактор вопросов», чтобы подготовить свой. В наборе три раунда по 24 вопроса и отдельный финал. В своём наборе можно оставить 1–3 раунда, в каждом до 8 тем и до 8 вопросов в теме.
2. В стартовом наборе 18 тем для компании разных возрастов. В первом раунде есть фильмы по вещам, блюда, цветы и города по фото. Во втором — актёры, песни, мультфильмы, настольные игры и инструменты. В третьем — праздники, пословицы по картинкам, сказки, реклама и города России. У каждого вопроса можно изменить цену, ответ, подсказку и фото. [Авторы и лицензии фотографий](https://stas5252.github.io/muzloto/quiz/credits.html).
3. «Скачать набор» сохраняет JSON вместе с фото. Импорт этого файла заменяет текущий черновик после подтверждения.

Черновик и активная комната хранятся в браузере ведущего. Смена браузера требует импорта файла. Файл набора содержит ответы и фото, поэтому его стоит хранить у ведущего. На телефоны игроков отправляются только состояние комнаты, счёт и право на ответ.

## Партия

- Ведущий создаёт комнату. До 12 игроков входят по QR-коду и вводят имя. Нажмите «Скопировать ссылку ТВ» на пульте и откройте её в браузере телевизора. Пульт можно оставить на телефоне. На ТВ видны табло, вопросы и результаты. «Экран ТВ» также можно открыть во второй вкладке ведущего и перенести на экран по HDMI.
- После выбора обычного вопроса или вопроса с двойной ценой кнопка «Ответить» появляется у игроков сразу. Первым отвечает игрок, чьё нажатие первым дошло до ведущего. При неверном ответе очки вычитаются, а право ответа получает следующий в очереди. Нейтральный ответ передаёт очередь без штрафа. Неверный ответ и ответ без штрафа не закрывают вопрос.
- «Двойная цена» влияет на начисление и штраф. Вопрос с передачей можно отдать выбранному игроку или открыть для всех. Подсказки и правильные ответы ведущий открывает вручную.
- Между раундами есть перерыв со счётом. Он переносится в следующий раунд. Если остались вопросы, ведущий подтверждает пропуск. Финал открывается с табло последнего раунда.
- В финале каждый может поставить от нуля до своего положительного счёта и написать ответ. Ведущий отмечает верные ответы перед выводом результата.
- Основная ссылка открывает главное меню. Если в браузере есть сохранённая комната, нажмите «Продолжить игру», чтобы вернуться к текущему вопросу или табло. Обновление страницы комнаты восстанавливает её сразу. Игрок в той же комнате и браузере сохраняет имя и счёт.

Однораундовые наборы открываются как один раунд. Для полного набора нажмите «Стартовый набор» в редакторе. Уже начатая комната продолжится со своим набором.

В сети GitHub Pages используются Supabase Realtime и резервный MQTT. В одной сети Wi‑Fi можно запустить версию без внешнего подключения командой `npm start`, открыть `http://localhost:3000/quiz/` и показать QR-код игрокам. Если компьютер выбрал не ту сеть, используйте его адрес Wi‑Fi вместо `localhost` на экране ведущего.

Проверка правил игры запускается командой `npm run test:quiz`. После запуска локального сервера команда `npm run test:quiz:browser` проверяет партию с мобильным пультом, отдельным браузером ТВ и 11 игроками в Chromium. Чтобы проверить опубликованную версию, укажите её ссылку в переменной `QUIZ_URL`.
