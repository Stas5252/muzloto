# Вне очереди

Отдельный квиз для компании. [Открыть на GitHub Pages](https://stas5252.github.io/muzloto/quiz/).

## Подготовка

1. Откройте «Редактор вопросов». Стартовый набор состоит из трёх раундов по 20 вопросов и финала. В 28 вопросах есть фотографии. В своём наборе можно оставить 1–3 раунда, в каждом до 8 тем и до 8 вопросов в теме.
2. У каждого вопроса есть цена, ответ, необязательная подсказка и фото. Тема «Вика в кадре?» во втором раунде. В ней четыре примера с реквизитом, которые можно заменить своими фото, вопросами и ответами. [Авторы и лицензии фотографий](https://stas5252.github.io/muzloto/quiz/credits.html).
3. «Скачать набор» сохраняет JSON вместе с фото. Импорт этого файла заменяет текущий черновик после подтверждения.

Черновик и активная комната хранятся в браузере ведущего. Смена браузера требует импорта файла. Файл набора содержит ответы и фото, поэтому его стоит хранить у ведущего. На телефоны игроков отправляются только состояние комнаты, счёт и право на ответ.

## Партия

- Ведущий создаёт комнату. Игроки входят по QR-коду и вводят имя. «Экран ТВ» можно открыть в дополнительном окне **того же браузера ведущего** и перенести на второй экран или показать через HDMI.
- После выбора вопроса ведущий открывает кнопки. Первым отвечает игрок, чьё нажатие первым дошло до ведущего. При неверном ответе очки вычитаются, а право ответа получает следующий в очереди. Нейтральный ответ передаёт очередь без штрафа. Неверный ответ и ответ без штрафа не закрывают вопрос.
- «Двойная цена» влияет на начисление и штраф. Вопрос с передачей можно отдать выбранному игроку или открыть для всех. Подсказки и правильные ответы ведущий открывает вручную.
- Между раундами есть перерыв со счётом. Он переносится в следующий раунд. Если остались вопросы, ведущий подтверждает пропуск. Финал открывается с табло последнего раунда.
- В финале каждый может поставить от нуля до своего положительного счёта и написать ответ. Ведущий отмечает верные ответы перед выводом результата.
- Обновление страницы ведущего восстанавливает комнату. Игрок в той же комнате и браузере сохраняет имя и счёт.

Однораундовые наборы открываются как один раунд. Для полного набора нажмите «Стартовый набор» в редакторе. Уже начатая комната продолжится со своим набором.

В сети GitHub Pages используются Supabase Realtime и резервный MQTT. В одной сети Wi‑Fi можно запустить версию без внешнего подключения командой `npm start`, открыть `http://localhost:3000/quiz/` и показать QR-код игрокам. Если компьютер выбрал не ту сеть, используйте его адрес Wi‑Fi вместо `localhost` на экране ведущего.

Проверка правил игры запускается командой `npm run test:quiz`.
