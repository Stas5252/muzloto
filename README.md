# 🎵 МузЛото — Музыкальное Бинго для вечеринок и компаний

Интерактивное музыкальное лото с бочонками, живым поиском любых песен из интернета и автоматической проверкой карточек. Играйте на большом экране ТВ или компьютера, а игроки участвуют со своих смартфонов!

🌐 **Играть онлайн (GitHub Pages)**: [https://stas5252.github.io/muzloto/](https://stas5252.github.io/muzloto/)  
📱 **Пульт ведущего**: [https://stas5252.github.io/muzloto/tv.html](https://stas5252.github.io/muzloto/tv.html)
📱 **Карточка игрока**: [https://stas5252.github.io/muzloto/play.html](https://stas5252.github.io/muzloto/play.html)

## Пульт на телефоне и отдельный экран ТВ

1. Откройте пульт ведущего на телефоне, выберите треки и создайте комнату.
2. Нажмите «Скопировать ссылку ТВ» и откройте её в браузере телевизора.
3. Нажмите «Включить звук на ТВ» на телевизоре. Оставьте пульт открытым на телефоне.

Пульт управляет бочонками, паузой и перемоткой. ТВ показывает лобби с QR-кодом, сыгравшие треки и карточку победителя. Когда ТВ воспроизводит облачную запись или онлайн-превью, звук пульта отключается. Если трек выбран из локальной папки на телефоне, он по-прежнему звучит с телефона.

## 🌟 Возможности

- **🎱 Настоящее русское лото**:
  - Каждому треку присваивается номер бочонка.
  - Бочонки вытягиваются из мешка **случайно** (№ 22, № 7, № 14...) с традиционными народными прозвищами («Утята», «Топорики», «Барабанные палочки»).
  - На карточках игроков в телефонах чётко указан номер бочонка и название песни.
- **🎵 Основной набор из 43 песен**:
  - По умолчанию отрывок звучит один раз, и через 4 секунды игра вытягивает следующий бочонок.
  - Чтобы использовать полные записи, нажмите «Подключить папку с музыкой» на экране ведущего. Счётчик покажет, сколько файлов совпало с набором.
  - Кнопка «Доиграть трек» запускает полную запись с начала и ждёт её окончания перед автопереходом. Браузер читает файлы из выбранной папки ведущего.
- **🔍 Поиск любых треков из интернета**:
  - Находите любых артистов и песни за 1 секунду с предварительным прослушиванием отрывка.
- **🔥 Готовые коллекции хитов (1 клик)**:
  - *«Новая школа: Крид, Дора, SODA LUV, Toxi$, Big Baby Tape, OG Buda»*
  - *«Хиты 90-х и 2000-х: Руки Вверх, Иванушки, Тату, Звери»*
  - *«Русский Рок & Легенды: Кино, Король и Шут, Би-2, Сплин, Ария»*
  - *«Мировые Поп-Хиты: Queen, Michael Jackson, Dua Lipa, The Weeknd»*
  - *«Современные Чарты: Anna Asti, Macan, Баста, Miyagi, JONY»*
  - *«Саундтреки & Кино: Интерстеллар, Пираты Карибского моря, Брат 2»*
- **📋 Табло выпавших бочонков (Call Board)**:
  - Лента всех сыгравших номеров для удобной сверки карточек.
- **🏆 Проверка БИНГО на экране ТВ**:
  - При нажатии «БИНГО» карточка победителя с подсветкой собранной линии выводится на экран ТВ для всеобщего подтверждения.

## 💻 Локальный запуск (Node.js)

```bash
# 1. Установите зависимости
npm install

# 2. Запустите сервер
npm start
# или
node server.js
```

Сервер запустится на `http://localhost:3000`.
- Чтобы разрешить сброс общего рейтинга с экрана ведущего, задайте `MUZLOTO_STATS_RESET_PASSWORD` в окружении перед запуском Node.js. При сбросе браузер запросит этот пароль.
- ТВ / Ведущий: `http://localhost:3000/tv.html`
- Игроки: `http://IP_КОМПЬЮТЕРА:3000/play.html` (или по QR-коду с экрана ТВ).
